# TestGennie Test Case Form

Builds a `/generate-qa-tests` request for the TestGennie Claude Code skill (SUFS Azure DevOps, ApplyPlatform project by default).

Open the form, enter a PBI or user story URL or ID, optionally add a test plan URL, pick the context sources, then click **Copy Request** and paste it into Claude Code.

Everything runs in the browser; nothing is sent anywhere.
